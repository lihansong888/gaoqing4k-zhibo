# 高清4K直播

**高清4K直播** 是基于开源 Android 播放项目 Box 进行二次开发的个人直播应用项目。

## 项目说明

- 项目名称：高清4K直播
- Android 应用，面向电视、电视盒子及 Android 设备
- 保留原项目的直播播放、频道分组、节目单及播放器相关能力
- 频道分组密码验证保留，普通用户不能关闭密码验证
- 本项目只在独立仓库和开发分支中维护

## 开发分支

当前开发分支：`work/gaoqing4k`

## 构建

使用 Android Studio 打开项目，等待 Gradle 同步完成后，根据需要选择 ABI、品牌和运行模式组合构建 APK。

生成的 APK 文件名以“高清4K直播”开头。
